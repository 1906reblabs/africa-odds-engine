Competition Coverage

10 African Competitions

Domestic leagues, continental cups, and international windows. Each with African-specific edge notes.

PSL — Premier Soccer League
🇿🇦 South Africa · Priority 1
Active
Home advantage systematically overpriced. Away form in SA undervalued by global models. Squad rotation during CAF weeks creates pricing gaps.
NFD — National First Division
🇿🇦 South Africa · Priority 2
Active
Extremely low global bookmaker attention. Largest domestic information asymmetry. Local ground conditions never priced in.
NPFL — Nigeria Premier Football League
🇳🇬 Nigeria · Priority 3
Active
Heavily undertracked by global bookmakers. Largest information asymmetry. Local travel fatigue is systematically unpriced.
Botola Pro — Moroccan Premier League
🇲🇦 Morocco · Priority 4
Active
Undertracked despite Morocco World Cup exposure. Ramadan schedule disruption ignored. Desert heat effects unpriced.
Egyptian Premier League
🇪🇬 Egypt · Priority 5
Active
Al Ahly and Zamalek dominance creates extreme odds compression. Strong underdog value in away fixtures. Ramadan effects ignored.
KPL — Kenyan Premier League
🇰🇪 Kenya · Priority 6
Active
Near-zero global attention. Nairobi altitude unpriced. Derby square money creates underdog value on Gor Mahia / AFC Leopards fixtures.
CAF Champions League
🌍 Africa (multi) · Priority 7
Continental
Cross-country travel fatigue massively underpriced. Altitude effects (Ethiopian venues) rarely priced. Weather differences ignored.
CAF Confederation Cup
🌍 Africa (multi) · Priority 8
Continental
Less covered than CAF CL — even larger information gaps. Many matches priced on reputation, not current form.
CHAN — African Nations Championship
🌍 Africa · Priority 9
International
Home-based players only — bookmakers use stale club ratings. Largest model-vs-market gap of any African competition.
AFCON Qualifiers
🌍 Africa · Priority 10
International
Club-vs-country conflicts unpriced. Largest form variance of any international tier. Home crowd at African venues dramatically underpriced.

Deployment Guide

Live in 30 minutes.
Zero cost.

GitHub → GitHub Actions (cron) → Telegram. No server. No DevOps experience needed.

Time: ~30 min Cost: R0/month Steps: 6
Step 01
Create Telegram Bot
Open Telegram → search @BotFather → send /newbot → follow instructions → copy the API token.
⏱ 3 minutes
Step 02
Create 2 Telegram Channels
Channel 1: Main (private, subscribers join here). Channel 2: Admin Review (private, only you). Add your bot as Admin with Post Messages permission to both.
⏱ 5 minutes
Step 03
Get Free API Keys
· the-odds-api.com — free 500 req/month
· rapidapi.com → API-Football — free 100/day
· football-data.org — free tier
⏱ 8 minutes
Step 04
Fork Repo & Add Secrets
Fork this repo on GitHub → Settings → Secrets → Actions → add: BOT_TOKEN, CHANNEL_ID, ADMIN_ID, ADMIN_CHANNEL_ID, THE_ODDS_API_KEY, RAPID_API_KEY, PUBLISH_MODE
⏱ 7 minutes
Step 05
Enable GitHub Actions
Repo → Actions tab → Enable workflows → Click "Run workflow" on scheduler.yml to trigger the first run manually.
⏱ 2 minutes
Step 06
Verify End-to-End
Watch the Actions log. Check your admin review channel for the first signal card. Approve it. Verify it appears in the main channel.
⏱ 5 minutes
⚠
GitHub Actions free tier
Free plan: 2,000 minutes/month. ABIN uses ~1,800 min/month (6 runs/day × ~10 min). If you exceed this, reduce the cron to every 6 hours. Never costs more than ~$4/month to upgrade to GitHub Pro.
